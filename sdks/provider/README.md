# Provider SDK

The provider SDK has [Python](python/) and [Rust](rust/) implementations of the
same [MPPI protocol](../../docs/protocol.md). Both consume the shared conformance
fixtures and preserve the same payment authority and amount rules.

Start with the [provider quickstart](../../docs/provider-quickstart.md) for
installation, native CLI onboarding and SDK composition in either language.

The provider supplies token requirements, actual usage, final outcomes and
available session evidence. Public integration definitions are in
[SDK interfaces](../../docs/sdk-interfaces.md).
